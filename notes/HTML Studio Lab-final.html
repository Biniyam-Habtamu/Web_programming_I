Words you will meet Plain-English meanings of the HTML words in this course
tag
The markers around content: <p> opens, </p> closes.
element
The whole thing: opening tag, content, closing tag.
attribute
Extra information inside the opening tag: name="value", like href or alt.
nesting
Elements inside elements, like boxes inside boxes. Close the inner one first.
head / body
head: information about the page. body: everything shown on it.
empty element
No content and no closing tag: img, br, hr, input, meta, link.
block / inline
Block starts a new line at full width; inline sits inside a line of text.
class / id
class: a name many elements share. id: a unique name for one element.
semantic
An element whose name says what the content is: header, nav, article, footer.
path
The address of a file: images/photo.jpg, ../index.html.
entity
A code for a special character: &lt; for <, &copy; for ©.
form control
Something the reader fills in or clicks: input, select, textarea, button.
API
A feature the browser offers to JavaScript, like localStorage or geolocation.

    Reference

    The elements you use on your profile page.

    HTML elementUse it for
    <!DOCTYPE html>First line of every page. Tells the browser this is modern HTML.
    <head> / <body>Information about the page / everything shown on the page.
    <title>The name in the browser tab. Goes in the head.
    <link rel="stylesheet" href="style.css">Connects a stylesheet. Goes in the head, no closing tag.
    <h1> … <h2>Main heading (one per page) and section headings.
    <p>A paragraph of text.
    <ul> + <li>A list and its items. <ol> for a numbered list.
    <a href="…">A link. href is the address it goes to.
    <img src="…" alt="…">An image. src is the file, alt describes it. No closing tag.
    <header> <main> <section> <footer>Meaningful regions of the page.
    class="card"An attribute that names an element so CSS can select it with .card.
